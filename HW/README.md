Цель работы: Освоить принципы построения лексеров, парсеров и систем трансляции,
а также научиться преобразовывать произвольный конфигурационный язык в структурированный формат XML.

Задачи:
1. Разработать грамматику учебного языка.
2. Реализовать лексер (разбиение текста на токены).
3. Реализовать парсер (построение структуры данных и обработка констант).
4. Реализовать подстановку констант вида .(NAME)..
5. Преобразовать полученную структуру в XML.
6. Добавить обработку синтаксических ошибок с указанием строки и позиции.
7. Добавить красивый форматированный вывод XML.
8. Провести тестирование на нескольких конфигурационных файлах.

Используемые технологии:
1. Python 3.13
2. Работа с деревьями XML: xml.etree.ElementTree
3. Форматирование XML: xml.dom.minidom
4. Работа через терминал (macOS + PyCharm)
5. Файл программы config20.py
6. Вариант 20

Полная реализация включает:
1) класс Lexer — разбор текста на токены
2) класс Parser — синтаксический анализ языка
3) класс ошибки ParseError с координатами
4) функцию value_to_xml()
5) модуль translate() с красивым форматированием XML
6) main() для работы через stdin

Тесты:
--> Программа для запуска: python config20.py < "назавние теста"
1) game1.txt (игровой конфиг)
2) network.txt (сетевой конфиг)
3) base1.txt (конфигурация базы данных)
4) error_test.txt (конфиг для вывода ошибок)

Вывод:
В ходе выполнения работы был разработан полноценный транслятор учебного конфигурационного языка в XML.
Программа:
1) Корректно разбирает пользовательский язык.
2) Поддерживает вложенные словари, строки, числа, комментарии и константы.
3) Выводит форматированный XML.
4) Обрабатывает синтаксические ошибки.
5) Демонстрирует принципы создания простых компиляторов и парсеров.
