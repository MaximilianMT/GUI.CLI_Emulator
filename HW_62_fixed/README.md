1) Цель работы: Изучить основы разработки инструментов конфигурационного анализа и создать CLI-приложение, которое:
считывает текст учебного конфигурационного языка из файла;
выполняет синтаксический разбор;
вычисляет константы (!{имя});
преобразует входной конфиг в формат YAML;
выводит найденные синтаксические ошибки;
поддерживает массивы, строки, числа, объявления констант, ссылки на константы;
запускается через командную строку.


2) Описание учебного конфигурационного языка
Язык включает следующие конструкции:

2.1 Числа:
123
0xFF
0X1a3

2.2 Строки:
"Это строка"

2.3 Имена переменных:
[A-Za-z_][A-Za-z0-9_]*

2.4 Массивы:
<< значение, значение, ... >>
<< 1, "text", 0x10 >>

2.5 Объявления констант:
var имя := значение
var host := "127.0.0.1"

2.6 Вычисления констант:
!{имя}
var port := 8080
var data := << !{port}, 1, 2 >>


3) Используемые технологии:
Python 3.x
Lark — специализированный инструмент синтаксического разбора (парсер LALR)
PyYAML — генерация YAML
argparse — обработка аргументов командной строки
macOS + PyCharm — среда разработки


4) Структура CLI-инструмента
Программа реализована в одном файле Config20.py и содержит следующие компоненты:

1. Грамматика Lark:
Описывает синтаксис языка (var, :=, массивы << >>, ссылки !{name}, числа, строки).

2. Парсер Lark (LALR):
Строит дерево разбора (parse tree) по грамматике.

3. Transformer (ToPython):
Преобразует дерево разбора в структуру Python:
числа → int
строки → str
массивы → list
!{имя} → вычисление значения из таблицы переменных

4. Таблица переменных:
Сохраняет значения, объявленные через var.

5. CLI-интерфейс:
python3 Config20.py -i tests/network.txt

6. Вывод результата в формате YAML


5) Тестовые конфигурации (3 предметные области):

1. Тест 1 (сетевые конфигурации) network.txt
var host := "192.168.1.10"
var port := 443
var proto := "tcp"
var server := << !{host}, !{port}, !{proto} >>

вывод YAML:
host: 192.168.1.10
port: 443
proto: tcp
server:
  - 192.168.1.10
  - 443
  - tcp

2. Тест 2 (Игровая модель) game.txt
var name := "Knight"
var hp := 150
var inventory := << "sword", "shield", !{hp} >>

Вывод YAML:
name: Knight
hp: 150
inventory:
  - sword
  - shield
  - 150

3. Тест 3 (Финансовая запись) finance.txt
var price := 199
var tax := 21
var receipt := << "ItemA", !{price}, !{tax} >>

Вывод YAML:
price: 199
tax: 21
receipt:
  - ItemA
  - 199
  - 21

4. Тест 4 (ошибки вывода) error.txt
var host := "127.0.0.1"
port := 8080          # ← Ошибка! Пропущено ключевое слово var
var data := << !{host}, !{port} >>

Пример сообщения об ошибке:
[SYNTAX ERROR] Синтаксическая ошибка (строка 2, колонка 1): ...

Ошибки выявляются для:
неправильно закрытых массивов
отсутствия var
неизвестных констант
неверного токена

6) Команды для запуска тестов:
1. python3 Config20.py -i tests/network.txt
2. python3 Config20.py -i tests/game.txt
3. python3 Config20.py -i tests/finance.txt
4. python3 Config20.py -i tests/error.txt
